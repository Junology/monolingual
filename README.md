# monolingual

A cross-platform Flutter app for translation-free vocabulary development via synonyms and contextual usage.

The project is released under the BSD 2-Clause License (see [LICENSE](LICENSE)).

## Features

- Visual presentation of synonym relationships
- Browsing word data: variants (conjugatiosn, plurals, etc), synonyms, and usage examples
- Both desktop and mobile support (see below)
- Quiz mode

## Supported Platforms

The app is developed with the Flutter/Dart framework.
The following platforms are the primary targets.

- Android
- Linux
- Windows

**Note:**
While iOS and macOS are not actively maintained or tested in this repository, it should technically be possible to build the app for those platforms.
