# monolingual

A cross-platform Flutter app for translation-free vocabulary development via synonyms and contextual usage.

The project is released under BSD 2-Clause License (see [LICENSE](LICENSE)).

## Key Features

- Recognition of words through synonyms and example usages instead of translation.
- Full control to add, edit, and organize words, synonym groups, and usage examples.
- Quiz mode prompting word recall from synonyms.
- Cross-platform; built with Flutter.
